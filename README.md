# 🌙 moodtod — your space for support

**moodtod** is a web application designed for emotional and psychological support. It doesn't replace a professional psychologist, but it can be a friend who listens when you need it most.

This project is based on my bachelor's thesis — a virtual conversational agent for psycho-emotional support using generative AI.

---

## 🧠 The Idea

In a world full of loneliness and anxiety, it's important to have a place where you can say something important and be heard. **moodtod** is that space.

It doesn't give advice, doesn't judge, doesn't treat. It's simply **here for you**.

---

## ✨ Features

- 🤖 **AI Assistant** — responds briefly, warmly, without unsolicited advice
- 🕊️ **Minimalist Design** — nothing extra, just you and the bot
- 📝 **Typewriter Effect** — creates the feeling of a real conversation
- 🧠 **Conversation Context** — remembers the last few messages
- ⚠️ **Ethical Approach** — clearly states it's AI, not a human
- 🆘 **Crisis Support** — provides hotline contacts when needed

---

## 🛠️ Technologies

- **HTML5, CSS3, JavaScript (Vanilla)**
- **Google Gemini API** — response generation
- **GitHub Pages** — free hosting

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Kateryna-Havryliuk/moodtod.git
   ```

2. Open `index.html` in your browser.

3. (Optional) Add your Gemini API key to the `GEMINI_API_KEY` variable in the JavaScript.
